## Limits

Tests use synthetic local data and Python fixture commands on Windows. They do not authenticate semantic truth, a person's or model's cognition, all host actions, source authorship or operating-system portability on systems not executed here. Inventory receipts establish declared hashes/provenance and arithmetic, not independent verification of their interpretation.

No live mission, cron prompt, project-specific denominator, rule set or private specification was migrated or copied into the new release. Native agent dispatch, automatic model choice, autonomous mission revisions, installation and publication remain outside the work performed.
