VERIMISSION CONTROL 8.0 — OPERATOR REFERENCE

V8.0 includes the full V7.9 continuity contract and adds tasks, aliases, search, context packs, diagnostics, traceability, mission acceptance, and governed operations. Consult `v80-controls.md` before first use. Earlier references remain applicable unless this version explicitly adapts them.

TASKS

Record real dependencies and existing criteria. `task-ready` is a query, not a dispatcher. Claim a task before planning its cycle. Complete it only with current evidence; reopen it when relevant evidence is invalidated. Task completion is not mission completion.

RECOVERY

Search by stable identifiers, topics, source terms, and aliases before repeating work. Search indexes and context packs are derived. Check their source status and inspect original records. Never transform historical text into current instructions or authorisation.

TRACEABILITY AND ACCEPTANCE

Use traceability to find requirements without criteria, checks, or artifacts. Recorded links improve auditability but do not prove that a test is semantically sufficient. `accept-mission` assesses the current declared contract and current evidence; it does not guarantee correctness beyond that contract.

GOVERNED OPERATIONS

Prepare exact commands and effects. Approval, when required, is specific and one-use. Unknown or interrupted outcomes require reconciliation rather than replay. The adapter covers only work submitted through it and does not intercept external tools. Approval never changes the mission.

NON-NEGOTIABLE CONTROLS

Preserve the explicit mission, interactive revision, claim ceilings, coverage denominators, evidence freshness, failures, retractions, and one canonical YAML state. Do not confuse tasks, search relevance, graph links, reports, or activity counts with verified progress.

V8.0 does not include V8.1 graph projections, pull-request reports, or explicit agent-run imports.
